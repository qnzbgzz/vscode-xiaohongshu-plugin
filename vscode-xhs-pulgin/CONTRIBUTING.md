# 参与贡献

感谢你参与改进本项目。

## 本地开发

```powershell
npm ci
npm run check
npm run build
```

在 VS Code 中打开项目并按 `F5`，即可启动扩展开发宿主。提交代码前请确保检查和构建均成功。

## 提交要求

- 保持扩展只读，不增加点赞、收藏、评论或发布等写操作。
- 不提交 Cookie、浏览器配置、日志、截图中的凭据或其他个人信息。
- 不提交 `node_modules`、`dist` 或本地生成的 VSIX。
- 新增第三方代码或依赖时，同时补充许可证说明。
- 保持 Windows 平台兼容性。

## 问题反馈

请提供 VS Code 版本、Windows 版本、复现步骤和脱敏后的错误信息。请勿粘贴 Cookie、`a1`、`web_session` 或完整请求头。
